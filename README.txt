RPAP(Role, Purpose, Action, Print) 형태로 지방자치단체에서 사용하는 공문초안 작성기를 지침으로 만들고 싶어.

[RPAP 지침]

Role(역할): 너는 대한민국 지방자치단체(예: 충청남도 논산시청) 공무원이다. 
공문 초안을 작성하는 담당자의 입장에서 문서를 작성한다.

Purpose(목적): 지방자치단체 내부 및 외부 기관과의 협조, 보고, 안내 등에 활용할 공문 초안을 작성한다.
공문은 반드시 다음의 세 부분을 포함해야 한다:
1) 사업 추진 배경
2) 협조 요청 사항
3) 일정 안내

Action(행동): 사용자가 제시한 주제를 바탕으로, 지방자치단체에서 실제 사용하는 공문 형식에 맞추어 초안을 작성한다. 
내용은 간결하고 행정 문서에 맞게 정중하게 작성하며, 불필요한 표현은 배제한다.

Print(출력 형식): 최종 출력은 공문 형식을 따른다. 문단 구성은 아래와 같다.

[공문 초안]

1. 사업 추진 배경
 ○ … (해당 사업 또는 사안의 필요성과 추진 배경 설명)

2. 협조 요청 사항
 ○ … (관련 부서 또는 기관에 요청할 사항 구체적으로 기재)

3. 일정 안내
 ○ … (추진 일정 및 세부 일정, 기한 명시)

Sub FillNumbersToA3()
    Dim lastRow As Long
    Dim targetCount As Long
    Dim i As Long
    
    ' A3의 값을 읽어옴
    targetCount = Range("A3").Value
    
    ' 잘못된 값(0 이하 또는 비어 있음)이면 종료
    If targetCount <= 0 Then
        MsgBox "A3에 올바른 숫자를 입력하세요.", vbExclamation
        Exit Sub
    End If
    
    ' 현재 B열의 마지막 데이터 행 찾기
    lastRow = Cells(Rows.Count, "B").End(xlUp).Row
    
    ' 기존 데이터 전체 지우기 (B2 이후)
    If lastRow >= 2 Then
        Range("B2:B" & lastRow).ClearContents
    End If
    
    ' 1부터 A3의 값까지 채우기
    For i = 1 To targetCount
        Range("B" & (i + 1)).Value = i
    Next i
End Sub

Sub FillNumbersC_Skip369()
    Dim target As Long
    Dim n As Long
    Dim r As Long
    Dim lastRow As Long
    
    ' A3 값 확인
    If Not IsNumeric(Range("A3").Value) Then
        MsgBox "A3에 숫자를 입력하세요.", vbExclamation
        Exit Sub
    End If
    
    target = CLng(Range("A3").Value)
    If target <= 0 Then
        MsgBox "A3에는 1 이상의 정수를 입력하세요.", vbExclamation
        Exit Sub
    End If
    
    ' 기존 값 정리: C2 이후 모두 비우기
    lastRow = Cells(Rows.Count, "C").End(xlUp).Row
    If lastRow < 2 Then lastRow = 2
    Range("C2:C" & lastRow).ClearContents
    
    ' C2부터 채우기 (3/6/9 포함된 수는 건너뜀)
    r = 2
    For n = 1 To target
        If Not Contains369(n) Then
            Cells(r, "C").Value = n
            r = r + 1
        End If
    Next n
End Sub

Private Function Contains369(ByVal n As Long) As Boolean
    Dim s As String
    s = CStr(n)
    Contains369 = (InStr(1, s, "3") > 0) Or (InStr(1, s, "6") > 0) Or (InStr(1, s, "9") > 0)
End Function

Private Sub CommandButton1_Click()
    Dim target As Long
    Dim n As Long, r As Long
    Dim lastRow As Long
    Dim txt As String
    
    ' 1) 목표값 결정: 비어 있으면 기본값 10
    txt = Trim(Me.TextBox1.Text)
    If txt = "" Then
        target = 10
    ElseIf IsNumeric(txt) Then
        target = CLng(txt)
        If target <= 0 Then
            MsgBox "1 이상의 정수를 입력하세요.", vbExclamation
            Exit Sub
        End If
    Else
        MsgBox "숫자를 입력하세요.", vbExclamation
        Exit Sub
    End If
    
    ' 2) 기존 출력 지우기 (E2↓)
    lastRow = Cells(Rows.Count, "E").End(xlUp).Row
    If lastRow < 2 Then lastRow = 2
    Range("E2:E" & lastRow).ClearContents
    
    ' 3) 369 로직 적용하여 E열 채우기
    r = 2
    For n = 1 To target
        If Me.CheckBox1.Value = True Then
            ' 체크됨: 3/6/9가 포함되면 개수만큼 별표, 아니면 숫자
            Dim c As Long
            c = Count369(n)
            If c > 0 Then
                Cells(r, "E").Value = String(c, "*")
            Else
                Cells(r, "E").Value = n
            End If
            r = r + 1
        Else
            ' 체크 해제: 3/6/9 포함된 숫자는 스킵
            If Not Contains369(n) Then
                Cells(r, "E").Value = n
                r = r + 1
            End If
        End If
    Next n
End Sub

Private Function Contains369(ByVal n As Long) As Boolean
    Contains369 = (Count369(n) > 0)

Private Function Count369(ByVal n As Long) As Long
    Dim s As String, i As Long, ch As String
    s = CStr(n)
    For i = 1 To Len(s)
        ch = Mid$(s, i, 1)
        If ch = "3" Or ch = "6" Or ch = "9" Then
            Count369 = Count369 + 1
        End If
    Next i
End Function
